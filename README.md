# AEGIS offline survival assistant (PWA edition, v4.4.0)

Open the site in Safari (iPhone) or Chrome (Android), then Add to Home Screen. The app works offline after the first load. The optional offline AI model (469 MB) is downloaded once from inside the app and verified with SHA-256.

NOT medically reviewed. NOT certified. Do not rely on it in a real emergency. Always contact emergency services when you can.
